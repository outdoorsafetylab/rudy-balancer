線上圖磚

tiles.rudymap.tw 把魯地圖的 Mapsforge 地圖畫成圖磚。圖磚網址從 tilejson 取得：

https://tiles.rudymap.tw/tilejson

tilejson 的 tiles 是 256 px 的圖磚，tiles_2x 是給高解析度螢幕的 512 px 版本；attribution 是出處標示。

Leaflet：

const tj = await (await fetch("https://tiles.rudymap.tw/tilejson")).json();
L.tileLayer(tj.tiles[0].replace(/\.png$/, "{r}.png"), { attribution: tj.attribution }).addTo(map);

MapLibre：

map.addSource("rudy", { type: "raster", url: "https://tiles.rudymap.tw/tilejson", tileSize: 256 });
map.addLayer({ id: "rudy", type: "raster", source: "rudy" });

速度與自架快取

tiles.rudymap.tw 是圖磚的來源，不保證速度與可用性，沒有 SLA，也沒有備援入口。要把圖放進網站或服務、給很多人看，而且需要穩定速度的，請自己架 CDN 或快取伺服器，以 tiles.rudymap.tw 為來源，讓使用者連到你的 CDN。

帶版本號的圖磚網址內容不會再變，回應是 Cache-Control: public, max-age=31536000, immutable，可以一直快取。tilejson 快取 5 分鐘，latest 網址快取一天；請沿用回應的快取時間，不要拉長。

使用規則

  • 網頁本身不用設定 User-Agent。自己架的快取伺服器或後端程式來抓圖磚時，請帶上名稱、版本和聯絡網址，例如 MySite/1.0 (+https://example.com/)，魯地圖或圖磚服務有重大變更或故障時，我們才通知得到你。
  • 版本號不要寫死在網址裡。每週更新後，舊版號的圖磚會回 404，請重新讀 tilejson，或改用 latest。
  • 只抓縮放層級 7–18 的圖磚，超出範圍會回 400。
  • 目前不限制來源網站，但保留對大量或異常使用限制存取的權利。

向量版 PMTiles (測試中)

向量版還在測試，檔案與樣式的內容可能隨時調整。

向量版是 PMTiles 格式，用 MapLibre 畫。每個地區有自己的地圖檔，多數地區另有高程檔，樣式所有地區共用一份；每週發布。以台灣為例：

  • 地圖：MOI_OSM_Taiwan_TOPO_Rudy.pmtiles，縮放層級 4–14。
  • 高程：taiwan_dem.pmtiles，畫地形陰影用，縮放層級 6–12，可以不用。
  • 樣式：rudymap_pmtiles_style.zip，所有地區共用。裡面有 style.json 與紙本風格的 paper.json、圖示 sprite/ 與 sprite-paper/、拉丁字形 glyphs/、version.txt。

樣式有兩個資料來源：topo 是地圖，dem 是高程。樣式裡的來源網址、glyphs 和 sprite 都是相對檔名，載入前請依來源 id 換成地圖檔和高程檔的完整網址。沒有高程檔，就拿掉 dem 來源、用到它的圖層，以及指向它的 terrain 設定 (如果有)。填不到來源請當成錯誤，不要沿用樣式裡寫的網址，否則可能畫出別的地區。

網頁用 MapLibre GL JS。地圖檔和高程檔請先問分流器一次，之後都直接讀它轉到的那一站。分流器會盡量把同一個網頁用戶端轉到同一個鏡像站，但那一站被排除或用戶端換了網路時會換站，讀到一半換站就可能接到另一份檔；如果每次讀取都再經過分流器，每次都會多一趟轉址。rudymap.tw 連不上時，可以改問備援入口 rudy.oslab.tw。樣式 zip 請解開，放在自己的網站。

const base = "https://example.com/rudymap/";      // 解開樣式 zip 的資料夾
const mirror = async (file) => {                   // 分流器挑的鏡像站
  const r = await fetch("https://rudymap.tw/v1/" + file, { method: "HEAD" });
  if (!r.ok) throw new Error(file + ": " + r.status);
  return r.url;
};
const map = await mirror("MOI_OSM_Taiwan_TOPO_Rudy.pmtiles");
const dem = await mirror("taiwan_dem.pmtiles");
maplibregl.addProtocol("pmtiles", new pmtiles.Protocol({ metadata: true }).tile);   // 出處讀地圖檔的 metadata
const style = await (await fetch(base + "style.json", { cache: "no-cache" })).json();
style.sources.topo.url = "pmtiles://" + map;
style.sources.dem.url = "pmtiles://" + dem;
style.glyphs = base + "glyphs/{fontstack}/{range}.pbf";
style.sprite = base + "sprite/sprite";
const header = await new pmtiles.PMTiles(map).getHeader();   // 地圖檔記著地區的中心
new maplibregl.Map({ container: "map", style, center: [header.centerLon, header.centerLat], zoom: header.centerZoom });

樣式 zip 放在自己的網站，每週要跟著地圖檔一起更新。檔名固定、內容每週會換，要避免瀏覽器用到上週的快取：style.json 照範例用 fetch(url, { cache: "no-cache" }) 讀；sprite 和字形是 MapLibre 自己讀的，請讓你的網站對這些檔回 Cache-Control: no-cache，或在 style.sprite、style.glyphs 的網址加上跟著版本變的參數 (例如 ?v= 加上 version.txt 的內容)。

地圖開著時，如果讀取開始失敗 (那一站壞了或被排除)，請重新問一次分流器，用它轉到的新網址重建地圖檔和高程檔的來源。

要把地圖檔也放在自己的網站，伺服器要支援 HTTP Range 請求，網頁在別的網域時要開 CORS。

網頁要放完整字形，不能只放 zip 裡的拉丁字形：用 openmaptiles/fonts v2.0 的 noto-sans.zip，字型是 Noto Sans Regular、Bold、Italic。MapLibre 預設用本機字型畫漢字、假名和韓文 (沒有把 localIdeographFontFamily 設成 false 時)，（、・ 這類全形標點要讀字形檔，讀不到時整張圖磚都畫不出來。

版本與圖層開關

地圖檔 metadata 的 version、樣式 metadata 的 taiwan-topo:version 和 version.txt 相同，就是同一週的地圖和樣式。地圖檔 metadata 的 taiwan-topo:dem_version 是同地區高程檔的內容版本，只在高程改變時才變，沒變就不必重新下載高程檔。

樣式 metadata 的 taiwan-topo:overlays 列出各個開關和它打開的分類，taiwan-topo:style-cats 是一直開著的分類，每個圖層的 metadata["taiwan-topo:cats"] 列出它需要的分類。需要的分類都開著，圖層才顯示，和魯地圖 Mapsforge 主題的選單相同。不做圖層開關的應用程式照樣式原樣畫即可。

  • 請照User-Agent 那段的格式帶 User-Agent。
  • 從 tilejson 取得的圖磚網址，請確認主機是 tiles.rudymap.tw 再用。

Mapsforge 離線地圖

魯地圖原本就是 Mapsforge 地圖，手機應用程式最常用的是這一套。每週發布，以台灣為例：

檔案 內容
MOI_OSM_Taiwan_TOPO_Rudy.map.zip地圖 MOI_OSM_Taiwan_TOPO_Rudy.map (10 公尺等高線)，附同名的 .poi
MOI_OSM_Taiwan_TOPO_Lite.map.zip輕量版地圖 (20 公尺等高線)，檔案較小
MOI_OSM_Taiwan_TOPO_Rudy_hs_style.zip主題 (有地形陰影，建議預設)：MOI_OSM.xml 與它的圖示資料夾
MOI_OSM_Taiwan_TOPO_Rudy_style.zip同一個主題，沒有地形陰影
MOI_OSM_Taiwan_TOPO_Lite_style.zip輕量版地圖用的主題
hgtmix.zip、hgt90.zip高程檔，每 1 度一個 .hgt，畫地形陰影用：hgtmix.zip 較精細，配 10 公尺等高線的地圖；hgt90.zip 是 90 公尺，配輕量版
MOI_OSM_Taiwan_TOPO_Rudy.poi.zip只有 POI (Mapsforge POI 資料庫)，給只要搜尋地點的應用程式
MOI_OSM_Taiwan_TOPO_Rudy.zip三合一包：地圖、主題、高程檔 (hgtmix) 一次下載，裡面分成 map/、mapthemes/、hgt/；地圖和主題一定是同一週的
MOI_OSM_Taiwan_TOPO_Lite.zip輕量版三合一包：輕量版地圖、主題 (MOI_OSM_Lite.xml)、hgt90，結構同上

其他地區的檔名與內容，見各地區的下載頁 (魯地圖官網)。

在應用程式裡顯示

  1. 依下載規則下載地圖、主題，要地形陰影再加高程檔，各自解開。
  2. 主題要整個資料夾一起放：主題 XML (例如 MOI_OSM.xml，輕量版是 MOI_OSM_Lite.xml) 用相對路徑讀旁邊的圖示資料夾，只留 XML 會畫不出圖示。三合一包的 mapthemes/ 已經是這個樣子。
  3. 高程檔解開後把 .hgt 放在同一個資料夾，交給地圖程式庫的地形陰影設定。有地形陰影的主題裡寫了 <hillshading />；不給高程檔時應該照常畫、只是沒有陰影，請在你用的程式庫確認一次。
  4. Android 或 Java 用 mapsforge：地圖檔用 MapFile 讀，主題用 ExternalRenderTheme 指到解開的 XML，地形陰影用 HillsRenderConfig 加 MemoryCachingHgtReaderTileSource 指到高程檔資料夾。Flutter 可以用 mapsforge_flutter。
  5. POI 檔是 SQLite 格式的 Mapsforge POI 資料庫，可用 mapsforge 的 POI 程式庫依位置或名稱查詢。

主題 zip 裡的 MOI_OSM.pdf、MOI_OSM.png 是圖例。主題內建的選單 (例如步道、等高線間距) 由應用程式依 XML 的 stylemenu 呈現；不做選單的應用程式照預設畫即可。

  • 解開樣式 zip，網址改成本機檔，例如 pmtiles://file:///…/MOI_OSM_Taiwan_TOPO_Rudy.pmtiles、file:///…/glyphs/{fontstack}/{range}.pbf、file:///…/sprite/sprite。

  • 全形標點在 zip 裡沒有字形。MapLibre Native (Android 13.7.1、iOS 7.0.0 實測) 會用手機字型畫；其他 SDK 或版本請用含全形括號的地名確認畫得出來。

從分流器下載檔案

檔案的網址是 https://rudymap.tw/v1/<檔名>。分流器不送檔案，只回 302 轉址到一個鏡像站，並留下一筆轉址紀錄。

  • 檢查有沒有新版，請用 HEAD。HEAD 一樣會轉址，跟著轉址就能拿到鏡像站的 Content-Length 等資訊，而且不會留下轉址紀錄。但各站的 Last-Modified、ETag 不能互相比較：同一份檔，有的站記的是上傳時間，ETag 的格式也各站不同，拿上次記下的值跟這次分到的另一站比，會誤以為有新版。要判斷新舊，請比對檔案裡的版本 (向量版是地圖檔 metadata 的 version)，或只拿同一站的值比。
  • 下載只 GET 一次。跟著轉址下載就好，不需要先另外發一個請求確認。
  • 續傳直接打轉址後的鏡像站網址，並帶 If-Range。鏡像站都支援 Range。重新打 rudymap.tw 可能被派到另一個站，兩站的檔案可能暫時不同；同一站也可能在下載途中換成新一週的檔。續傳時帶 If-Range，值用第一次回應的 ETag：檔案沒換會回 206，換過了會回 200 整份檔，這時請從頭寫，不要接上。整份重新下載則可以重新經 rudymap.tw。
  • rudymap.tw 連不上時，改用備援入口 rudy.oslab.tw，路徑不變。
  • 先確認空間。解開 zip 時要同時放 zip 與解出的檔，大約需要檔案兩倍的空間。

同一個檔重複打 rudymap.tw，不但會留下重複的紀錄、讓使用報告只能估算下載次數，每次還可能被派到不同的站。

兩個入口都連不上時的退路，見部署架構的「建議下游的退路順序」。

User-Agent：請標示應用程式名稱

我們每季公開使用報告，列出各應用程式的下載量。報告靠 User-Agent 辨識下載來自哪個應用程式。如果只帶著 Dalvik/2.1.0、Dart/3.5 這類函式庫或系統的預設值，我們就認不出是哪個應用程式，有重大變更或故障時也無從通知。

向 rudymap.tw 下載時，請在 User-Agent 標頭放上：

AppName/版本 (+聯絡網址)

例如：

MyHikingApp/2.1.0 (+https://example.com/contact)
TrailMaps/1.4.2 (+https://example.org/)
  • AppName：英數字、不含空白，能讓人認出是哪個應用程式。
  • 版本：應用程式的版本號。
  • 聯絡網址：網站或聯絡頁，有重大變更或故障時，我們可以通知你。
  • 後面可以接原本的系統資訊，例如 wadi/v.7.03.17 Dalvik/2.1.0 (Linux; U; Android 16; ...)。

常見的漏網之魚

  • 下載檔案的請求也要帶。應用程式裡常有不只一個 HTTP 元件：查詢更新用一個，實際下載大檔又用另一個 (背景下載、續傳用的函式庫)。只設定其中一個的話，真正的下載仍會是函式庫的預設值。請確認每一個會連到 rudymap.tw 的請求都帶同樣的名稱。
  • 預設值認不出是哪個應用程式。iOS 原生的網路元件 (URLSession) 會把執行檔名稱放在 User-Agent 最前面，那常是專案內部代號 (Flutter 專案預設是 Runner)；Dart 的 HttpClient 預設是 Dart/x.y。兩種都請明確設定成應用程式的名稱。
  • 不要只送 Mozilla/5.0。這看起來像瀏覽器，卻沒有任何可辨識的資訊。

各平台設定方式

  • Android (OkHttp)：加一個 interceptor，request.newBuilder().header("User-Agent", ua)。
  • Android (HttpURLConnection)：conn.setRequestProperty("User-Agent", ua)。
  • Android (DownloadManager)：request.addRequestHeader("User-Agent", ua)。
  • iOS (URLSession)：configuration.httpAdditionalHeaders = ["User-Agent": ua]；背景下載用的 session 也要設定。
  • Flutter / Dart：HttpClient()..userAgent = ua，或在 package:http 的請求加上標頭。

我們每季公開使用報告，向架設鏡像站的志工與圖資作者說明魯地圖被怎麼使用，報告裡會列出各應用程式的下載量；魯地圖有重大變更或故障時，也靠它通知各網站和應用程式的開發者。

  • 應用程式：照User-Agent 那段的格式帶 User-Agent。
  • 網頁：目前使用報告只依檔名與 User-Agent 分，瀏覽器的下載都算在「網頁瀏覽器」，還分不出是哪個網站。仍歡迎登記網站的主機名稱，有重大變更或故障時，我們才通知得到你。
  • 登記：到魯地圖 GitHub 開一個 issue，寫上產品名稱、網址 (網站；沒有網站的應用程式，給 Google Play 或 App Store 的頁面)、聯絡方式，以及 User-Agent 的開頭 (應用程式) 或網站的主機名稱 (網頁)。我們會登記到 downstreams.yaml。登記不是使用的前提，也不影響分流。

版權與出處

魯地圖的授權與散佈方式，請見魯地圖官網的「地圖版權與散佈說明」。地圖資料 © OpenStreetMap contributors；台灣的等高線與高程來自內政部。

  • 線上圖磚：標示 tilejson 的 attribution。
  • 向量版：標示地圖檔 metadata 的 attribution，裡面有這個地區的高程來源。樣式本身不帶出處，沒讀地圖檔的 metadata，地圖上就沒有任何出處；網頁用 pmtiles.Protocol({ metadata: true }) 即可 (見網頁的範例)。
